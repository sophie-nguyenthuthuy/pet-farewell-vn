# Security policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Pet Farewell VN,
please email **security@pet-farewell.vn** with:

- A description of the issue and where it lives in the code
- Steps to reproduce
- Your assessment of impact

**Please do not file a public GitHub issue.** We aim to acknowledge reports
within 2 business days and provide a remediation timeline within 7 days.

## Scope

In scope:
- This repository's source code
- The booking, payment, and admin flows
- Any deployed instance under `*.pet-farewell.vn`

Out of scope:
- Social engineering of staff
- Physical attacks on the cremation facilities
- Third-party services (Stripe, VNPay, Resend) — report directly to them

## Disclosure

We follow a coordinated disclosure model. Once a fix is shipped, we will credit
researchers who reported responsibly (unless anonymity is requested).
